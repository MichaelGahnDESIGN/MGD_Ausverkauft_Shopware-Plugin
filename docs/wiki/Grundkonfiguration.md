# Grundkonfiguration

Die Einstellungen befinden sich unter **Erweiterungen → Meine Erweiterungen → MGD Ausverkauft → Konfiguration**.

## Listing-Darstellung

**Keine Kennzeichnung** verändert Produktkarten nicht.

**Label oben rechts** zeigt ein rotes Ausverkauft-Label.

**Roter Rahmen + Label** ergänzt um die gesamte Produktkarte einen roten Rahmen.

## Texte

Standardlabel: `Ausverkauft`

Standardhinweis: `Dieser Artikel ist aktuell nicht verfügbar.`

Beide Texte können konfiguriert werden.

## Kaufbereich ausblenden

Ist die Option aktiv, wird bei erreichtem Grenzbestand das eigentliche Kaufformular nicht ausgegeben. Preis, Steuerinformationen, Lieferinformationen und übrige Produktdaten bleiben erhalten.

## Nur Abverkaufsprodukte berücksichtigen

Standardmäßig ist die Logik an Shopwares `isCloseout` gebunden. Das Plugin aktiviert Abverkauf nicht pauschal für alle Produkte.

Wird die Option deaktiviert, kann die Bestandsgrenze unabhängig von der Abverkauf-Eigenschaft verwendet werden.
