# MGD_Ausverkauft_Shopware-Plugin
Ein Shopware 6.7.x Plugin, dass es ermöglicht Produkte mit Bestand 0 im Shop zu behalten (Seite verschwindet bei Abverkäufen nicht). Dabei erhält das Produkt ein Label "Ausverkauft" im Label und Listings und der Warenkorb Button wird ausgeblendet, bis der Bestand wieder aufgefüllt wurde. Es gibt auch eine Bestandsgrenze (mindestens X im Bestand).
